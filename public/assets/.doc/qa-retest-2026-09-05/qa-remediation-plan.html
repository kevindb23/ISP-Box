Executive conclusion

The system is not ready for production sign-off. The most important defects are the technician work-orders HTTP 500, HTTP transport without HTTPS enforcement, inconsistent Plan CRUD responses, and server-error handling for rejected CSRF requests. The notification and compact-sidebar failures are separate UI/authorization issues. Several repeated checks represent one shared defect, so the seven root causes below are more useful than counting each symptom as a separate bug.
